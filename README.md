
# Exam Grade Calculator (Python)

A simple Python script that prompts for a student's numeric score and prints the corresponding letter grade using nested `if` / `elif` / `else` logic.

## Grading Scale

- A: 90–100  
- B: 80–89  
- C: 70–79  
- D: 60–69  
- F: below 60

## How It Works

1. The program asks for a student's score as an integer via input()
2. It checks the score against the grading thresholds.
3. It prints the result in the format: score = grade

## How to Run

```bash
python3 grade.py
